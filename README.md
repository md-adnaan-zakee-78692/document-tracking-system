# Document Tracking System

A Django-based Document Tracking System that allows users to create, track, approve, and reject documents through a role-based workflow.

## Features

* User authentication
* Role-based workflow
* Document approval/rejection
* Action history
* Dashboard

## Tech Stack

* Django
* Python
* SQLite
* HTML, CSS, Bootstrap

## Run the Project

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Visit: `http://127.0.0.1:8000/`
